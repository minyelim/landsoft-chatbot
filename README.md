# 🏢 랜드소프트 질문 챗봇

랜드소프트 `회사규정_2024_12.pdf`와 `신규입사자 온보딩 가이드(pptx)` 내용을 바탕으로
사내 규정에 대해 질문하면 답변해주는 챗봇입니다. 파이썬 + Streamlit + Gemini API로
만들어졌고, 웹 브라우저에서 채팅창처럼 사용합니다.

```
질문: 연장근로 시 식대는 얼마까지 지원되나요?
답변: 연장근무 시 연근식대는 실비로 지급되며, 1인 1식 1만5천원을 한도로 합니다.
      [출처: 회사규정 Ⅱ. 연장근로규정]
```

---

## 폴더 구성

```
landsoft_chatbot/
├── app.py                     ← 챗봇 본체 (Streamlit 앱)
├── requirements.txt           ← 설치해야 할 패키지 목록
├── .env.example                ← API 키 설정 예시 파일
├── run_windows.bat             ← 윈도우용 원클릭 실행 스크립트
├── run_mac.sh                  ← Mac/Linux용 원클릭 실행 스크립트
├── knowledge_base/             ← 챗봇이 참고하는 자료 (텍스트로 변환됨)
│   ├── 01_회사규정.txt
│   └── 02_온보딩가이드.txt
└── scripts/
    └── update_knowledge_base.py   ← 규정이 바뀌었을 때 자료를 다시 만드는 도구
```

## 1. 사전 준비

### 1) 파이썬 설치 확인
터미널(윈도우는 "명령 프롬프트" 또는 "PowerShell", Mac은 "터미널")을 열고 아래 명령을 입력하세요.

```bash
python --version
```

`Python 3.10` 이상이 나오면 OK입니다. (윈도우에서 `python`이 안 먹으면 `python3` 또는
`py`로 시도해보세요.) 없다면 https://www.python.org/downloads/ 에서 설치하세요.
**설치 시 "Add Python to PATH" 체크박스를 반드시 체크**해야 합니다. (이걸 놓쳐서
"파일을 찾을 수 없다"는 오류가 자주 발생합니다.)

### 2) Gemini API 키 발급 (무료)
1. https://aistudio.google.com/apikey 접속 후 구글 계정으로 로그인
2. **Create API key** 클릭 → 키가 발급되면 복사해두기
3. 무료 사용량 안에서는 비용이 청구되지 않습니다.

---

## 2. 설치 및 실행

### 방법 A. 원클릭 스크립트 사용 (제일 쉬움)

1. 이 `landsoft_chatbot` 폴더 전체를 원하는 위치(예: 바탕화면)에 둡니다.
2. **윈도우**: `run_windows.bat` 더블클릭
   **Mac**: 터미널에서 이 폴더로 이동한 뒤 `./run_mac.sh` 실행
   (최초 1회는 `chmod +x run_mac.sh` 로 실행 권한을 준 뒤 실행하세요)
3. 자동으로 가상환경 생성 → 패키지 설치 → 브라우저 실행까지 진행됩니다.
4. 브라우저가 열리면 왼쪽 사이드바에 Gemini API 키를 붙여넣고 바로 질문하면 됩니다.

### 방법 B. 명령어로 직접 실행

**반드시 `landsoft_chatbot` 폴더 안으로 이동한 뒤** 아래 순서대로 입력하세요.
(폴더 밖에서 실행하면 "파일이 없다"는 오류가 납니다 — 이게 이전에 겪으셨던 문제일 가능성이 높습니다.)

```bash
# 1) 이 폴더로 이동 (예시 경로이니 실제 위치에 맞게 수정)
cd landsoft_chatbot

# 2) 가상환경 생성 (최초 1회만)
python -m venv venv

# 3) 가상환경 켜기
#    윈도우:
venv\Scripts\activate
#    Mac/Linux:
source venv/bin/activate

# 4) 패키지 설치
pip install -r requirements.txt

# 5) 실행
streamlit run app.py
```

실행하면 자동으로 브라우저가 열리며 `http://localhost:8501` 주소로 챗봇이 뜹니다.
안 열리면 주소를 브라우저에 직접 입력하세요.

### API 키를 매번 입력하기 귀찮다면
`.env.example` 파일을 복사해서 이름을 `.env` 로 바꾸고, 그 안에 발급받은 키를 넣어두세요.
그러면 실행할 때마다 사이드바에 자동으로 채워집니다.

```
GEMINI_API_KEY=발급받은_키_붙여넣기
```

## 3. 사용 방법

- 화면 하단 입력창에 궁금한 규정을 자연스럽게 물어보면 됩니다.
  - "출장 갈 때 숙박비 한도가 얼마야?"
  - "재택근무는 입사한지 얼마나 지나야 신청할 수 있어?"
  - "전월세 보증금 지원 대상이 되려면 어떤 조건을 만족해야 해?"
  - "결혼하면 경조휴가 며칠 쓸 수 있어?"
- 답변 끝에 `[출처: ...]` 형태로 근거가 된 규정 항목이 함께 표시됩니다.
- 문서에 없는 내용을 물으면 "제공된 자료에서는 확인할 수 없습니다"라고 답하고
  경영관리팀에 문의하라고 안내합니다. (엉뚱한 답을 지어내지 않도록 설계했습니다.)
- 왼쪽 사이드바 **"🗑️ 대화 초기화"** 버튼으로 새 대화를 시작할 수 있습니다.

## 4. 규정/온보딩 자료가 바뀌었을 때 (자료 업데이트)

회사 규정 PDF나 온보딩 PPT 내용이 개정되면, 아래 명령으로 지식베이스(txt 파일)를
다시 만들면 챗봇이 최신 내용을 반영합니다. (가상환경이 켜진 상태에서 실행)

```bash
# 새 규정 PDF로 knowledge_base/01_회사규정.txt 갱신
python scripts/update_knowledge_base.py --pdf "새로운_회사규정.pdf" --out 01_회사규정

# 새 온보딩 PPT로 knowledge_base/02_온보딩가이드.txt 갱신
python scripts/update_knowledge_base.py --pptx "새로운_온보딩가이드.pptx" --out 02_온보딩가이드
```

`knowledge_base` 폴더 안에 `.txt` 파일을 몇 개 넣어두든 챗봇이 전부 자동으로 불러와
참고 자료로 사용하므로, 다른 사내 문서를 텍스트(.txt)로 저장해 이 폴더에 추가하기만
해도 답변 범위를 넓힐 수 있습니다.

## 5. 동작 원리 (간단 설명)

1. `knowledge_base` 폴더의 모든 텍스트를 앱 실행 시 한 번에 불러옵니다. (전체 문서가
   약 3만 자 정도로 크지 않아서, 별도의 검색(RAG) 없이 전체 내용을 그대로
   AI에게 참고자료로 전달하는 방식을 사용했습니다 — 구조가 단순해서 오류 날 확률이 낮습니다.)
2. 사용자가 질문을 입력하면, "이 문서 내용만 근거로 답하라"는 지시와 함께
   Gemini API로 전달합니다.
3. Gemini가 문서 내용을 바탕으로 답변을 생성해 채팅창에 표시합니다.

## 6. 자주 발생하는 오류 해결

| 증상 | 원인 / 해결 방법 |
|---|---|
| `streamlit: command not found` | 가상환경을 켜지 않았거나(`venv\Scripts\activate` / `source venv/bin/activate`), `pip install -r requirements.txt`를 안 한 경우입니다. |
| "파일을 찾을 수 없습니다" 계열 오류 | 터미널에서 **landsoft_chatbot 폴더 안**에 있는지(`cd landsoft_chatbot`) 먼저 확인하세요. `ls`(Mac) 또는 `dir`(윈도우)로 `app.py`가 보이는지 확인합니다. |
| 사이드바에 API 키를 넣었는데도 오류 | 키를 잘못 복사했거나 공백이 포함된 경우가 많습니다. https://aistudio.google.com/apikey 에서 키를 다시 복사해보세요. |
| 답변이 "확인할 수 없습니다"만 나옴 | 정상 동작입니다 — 질문이 두 문서(회사규정, 온보딩가이드)에 없는 내용일 때 나오는 안전장치입니다. |
| 포트(8501) 충돌 오류 | 다른 프로그램이 이미 8501 포트를 쓰고 있는 경우입니다. `streamlit run app.py --server.port 8502` 처럼 포트 번호를 바꿔 실행하세요. |
